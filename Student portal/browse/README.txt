CampusShare - Browse Equipment + Equipment Details

Files:
- index.html  : Browse catalog and equipment detail page structure
- styles.css  : Responsive styling for both views
- script.js   : Sample equipment data and page interactions

Run:
1. Keep all three files in the same folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. Select any equipment card to open its Details page.
4. Use the Browse Equipment button to return to the catalog.

Notes:
- This is a frontend prototype with sample data.
- Reservation form validates dates and shows a demo confirmation only.
- No real authentication, availability checking, or database writes are configured.
- Equipment photos are loaded from Unsplash URLs, so an internet connection is needed for those images.
- Connect the UI to your backend/database before using it for real reservations.
