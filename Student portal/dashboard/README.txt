CampusShare Student Dashboard (frontend prototype)

Files:
- index.html  : dashboard structure
- styles.css  : responsive visual styling
- script.js   : search, category filters, sort, reservation modal, notifications, profile menu and mobile navigation

Run:
1. Keep the three files in the same folder.
2. Open index.html in a modern browser, or use VS Code Live Server.

Notes:
- This is a frontend-only prototype using sample dashboard data.
- Reservation submissions update the visible request count only in the current browser session.
- No real account, database, approval workflow, or backend authentication is connected yet.
- Equipment photos and Google Fonts load from external URLs and therefore require internet access.
