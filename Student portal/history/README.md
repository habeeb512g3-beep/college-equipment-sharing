# CampusShare - Borrowing History & Custody Log

## Files
- `index.html` — page structure
- `styles.css` — responsive design and styling
- `script.js` — sample records and frontend interactions

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Included interactions
- Search records by equipment name, asset ID, serial number, lab or facility
- Filter by facility and semester
- Switch between All, Impacted and Reports views
- Navigate paginated history
- Open sample digital receipts and inspection certificates
- Export visible records as CSV
- Download a sample audit transcript as TXT
- Open the borrowing policy placeholder

## Important
This is a frontend-only prototype using sample data. It does not connect to Supabase or create official, signed audit records. Replace the sample policy text and data with approved institutional content before deployment. Add server-side authorization and immutable audit logging before treating this page as an official custody ledger.
