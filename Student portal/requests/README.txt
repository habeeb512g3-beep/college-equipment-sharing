CampusShare — My Equipment Requests

Files
- index.html: page structure and request content
- styles.css: responsive styling
- script.js: tabs, search, department filter, request actions, modal dialogs and toast messages

Run
1. Keep all three files in the same folder.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.

Notes
- This is a frontend demo with sample request data.
- Changes to requests are local to the browser page and are not stored in a database.
- Authentication, live inventory status, QR pass generation, notifications and pickup scheduling require backend integration.
- Equipment photos and Google Fonts load from external URLs and require an internet connection.
