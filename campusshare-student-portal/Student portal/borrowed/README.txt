CampusShare - Borrowed Equipment Page

Files:
- index.html: page structure
- styles.css: all layout and responsive styles
- script.js: demo interactions and live return countdown

Run:
1. Keep all three files in the same folder.
2. Open index.html in a browser, or use VS Code Live Server.

Notes:
- This is a frontend prototype with sample loan information.
- The QR pass is a visual demo and is not a real scannable authentication token.
- Extension and issue reports display demo confirmations; no records are sent to a server.
- Replace sample student, lab, and equipment details with verified project data.
