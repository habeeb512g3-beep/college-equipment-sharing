# CampusShare – Profile & Settings

A static frontend prototype based on the supplied CampusShare Profile & Settings reference.

## Files
- `index.html` – page structure
- `styles.css` – responsive styling
- `script.js` – demo interactions

## Run
Open `index.html` directly in a browser, or open this folder in VS Code and use Live Server.

## Notes
This is a frontend-only demo. Profile edits and device removal affect the current page session only. Notification switches are not persisted. Certificate upload is a file-selection placeholder and does not submit files to a server. University SSO, password changes, actual device-session revocation, certificate verification, and borrowing account data require backend/institutional integration.
