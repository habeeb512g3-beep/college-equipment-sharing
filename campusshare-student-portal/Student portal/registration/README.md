# CampusShare Registration Page

A responsive, frontend-only registration page based on the supplied CampusShare reference.

## Files
- `index.html` — semantic form markup
- `styles.css` — styling and responsive layout
- `script.js` — role selection, password strength, client-side validation, and demo messages

## Run
Keep all three files in the same folder and open `index.html` in a browser. For development, use VS Code Live Server.

## Important
This is a frontend demo, not a real account creation system. It does not create users or verify campus email addresses. Connect the form to your trusted backend / university SSO provider before deployment. Never store passwords in browser storage or expose privileged backend keys in frontend code.
